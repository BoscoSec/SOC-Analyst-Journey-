
# OSI Model

## What is the OSI Model?

The OSI Model is a framework that explains
how network communication works.

It contains 7 layers.

## The 7 Layers

| Layer | Name | Function |
|---|---|---|
| 7 | Application | User-facing network services |
| 6 | Presentation | Data formatting and encryption |
| 5 | Session | Manages communication sessions |
| 4 | Transport | TCP and UDP |
| 3 | Network | IP addressing and routing |
| 2 | Data Link | MAC addresses |
| 1 | Physical | Physical transmission |

## Why is this important for SOC?

As a SOC analyst, understanding network
layers helps me investigate suspicious
network traffic.

## What I learned

- TCP operates at Layer 4.
- IP operates at Layer 3.
- DNS commonly uses port 53.
