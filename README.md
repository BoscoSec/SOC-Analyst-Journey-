
# 🛡️ SOC Analyst Learning Journey

Welcome to my Cybersecurity and SOC Analyst learning journey!

This repository documents my progress as I develop the technical knowledge and practical skills required to become a Security Operations Center (SOC) Analyst.

My goal is to build a strong foundation in cybersecurity, understand real-world security threats, and gain hands-on experience with security monitoring, threat detection, and incident response.

## 🎯 Learning Objectives

- Understand networking fundamentals (TCP/IP, OSI Model, DNS, HTTP/HTTPS).
- Learn Windows and Linux operating systems.
- Understand Active Directory and Windows Event Logs.
- Gain hands-on experience with SIEM tools such as Wazuh and Splunk.
- Learn security alert investigation and incident triage.
- Understand MITRE ATT&CK framework.
- Develop Python skills for cybersecurity automation.
- Build practical SOC projects and home labs.
